# Agent Orchestration Policy

Agents are draft-only by default.

## Agents May

- Draft.
- Summarize.
- Flag.
- Recommend.
- Prepare reports.
- Create non-public suggestions.

## Agents Must Not Without Owner Approval

- Deploy production.
- Edit Stripe settings.
- Issue refunds.
- Change pricing.
- Change legal/policy text.
- Send customer campaigns.
- Change security settings.
- Delete data.

## Always Blocked

- Exposing secrets.
- Bypassing auth.
- Changing payout destination automatically.
- Deleting audit logs.
- Disabling safety gates.
