# Prompt Playbook Center

The Prompt Playbook Center is a governed library of original prompt templates for SONARA One.

Public names:

- AI Playbook Center
- Business Prompt Library
- Growth Prompt Library
- Creator Prompt Library
- Launch Prompt Builder
- Smart Workflow Templates
- Guided AI Tasks

The system provides draft prompts only. It does not call model providers directly, does not send customer messages, and does not publish output. Provider Gateway or another approved server-side gateway must handle AI calls, redaction, audit logs, and key management.

High-risk prompt outputs require Owner Confirmation Lock before use.
