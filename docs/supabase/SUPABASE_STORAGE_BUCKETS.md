# Supabase Storage Buckets

Launch bucket registry:

- `sonara-public-assets`: approved public assets only.
- `sonara-private-files`: private tenant files.
- `business-builder-documents`: Business Builder uploads.
- `creator-studio-media`: Creator Studio media under rights review.
- `growth-studio-imports`: Growth Studio imports.
- `research-lab-sources`: Research Lab review artifacts.
- `support-attachments`: support request attachments.
- `generated-media`: generated media requiring rights review.
- `exports`: user-requested exports.
- `vector-knowledge`: derived private knowledge chunks and metadata.

All buckets except explicitly approved public assets are private by default.
