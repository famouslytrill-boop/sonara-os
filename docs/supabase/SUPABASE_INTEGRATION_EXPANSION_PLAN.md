# Supabase Integration Expansion Plan

The Supabase Integration Control Center is a documented operating layer, not a live provider installer.

Planned integration areas:

- Auth and identity.
- Branching and Vercel preview.
- Edge Functions.
- Queues.
- Cron.
- Database webhooks.
- Storage buckets.
- Realtime dashboards.
- Vector search and AI.
- Vault and secret references.
- Foreign Data Wrappers.
- Provider health checks.

No table or registry stores actual secret values.
