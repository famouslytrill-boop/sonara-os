# API Provider Policy

API providers must be reviewed before production use.

## Required Fields

- Provider name.
- Purpose.
- Terms review status.
- Rate-limit policy.
- Cache policy.
- Fallback policy.
- Secret handling.
- Owner approval status for risky actions.

## Blocked By Default

- Frontend secrets.
- Risky scraping providers.
- Unofficial Google scraping.
- Unofficial WhatsApp automation.
- Customer messaging without consent.
