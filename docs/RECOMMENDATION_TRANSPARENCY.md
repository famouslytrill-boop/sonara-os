# Recommendation Transparency

Smart Recommendations, Growth Suggestions, Next Best Action, and Opportunity Ranking are advisory systems.

This layer does not copy X/xAI branding, source code, ranking logic, or feed mechanics. It is a transparent setup and operations ranking layer for SONARA One.

## Allowed Recommendations

- Complete profile.
- Add payment link.
- Add booking link.
- Create offer.
- Draft review request.
- Draft customer follow-up.
- Draft win-back campaign.
- Fix missing proof.
- Improve page copy.
- Resolve security warning.
- Finish onboarding.
- Update stale offer.
- Check failed payment.
- Review pending approval.

## Required Explanation

Every recommendation must show:

- Why it was suggested.
- Product area.
- Expected business value.
- Risk level.
- Owner approval requirement.
- Data used.
- Data not used.
- Confidence.
- Next action.

## Blocked Behavior

- Addictive social feed mechanics.
- Manipulative ranking.
- Discriminatory targeting.
- Hidden political persuasion.
- Fake urgency or scarcity.
- Fake reviews.
- Ranking based on sensitive personal attributes.
- Auto-sending campaigns.
- Customer messaging without consent.
- Predatory pricing pressure.
