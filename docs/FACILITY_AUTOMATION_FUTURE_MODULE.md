# Facility Automation Future Module

Facility automation and IoT features are not part of the launch path.

Disabled feature flag:
- `NEXT_PUBLIC_ENABLE_FACILITY_AUTOMATION=false`

Blocked before launch:
- Domoticz integration.
- MQTT broker setup unless separately approved.
- Device control.
- Covert monitoring.
- Emergency automation claims.
- Safety-critical automation.

Allowed now:
- Architecture notes and future review requirements.
