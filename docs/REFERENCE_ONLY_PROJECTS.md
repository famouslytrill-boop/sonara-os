# Reference-Only Projects

Status: intake registry view.

Reference-only means the team may read public materials for workflow ideas but must not copy source
code, templates, UI, database schema, tests, prompts, or branding.

## Reference and Concept Boundaries

- Use for architecture and workflow comparison.
- Do not import code.
- Do not add production dependency entries.
- Do not claim partnership or compatibility unless verified.
- Keep public UI labels honest: reference-only is not integrated.

## Examples in Current Registry

- `frappe/erpnext`: workflow reference only unless isolated self-hosting is legally reviewed.
- `organicmaps/organicmaps`: mapping reference only.
- `github/spec-kit`: spec-to-plan-to-tasks workflow inspiration.
- `FareedKhan-dev/train-llm-from-scratch`: education/reference only.
- `mathworks-robotics/awesome-matlab-robotics`: research reference only.
