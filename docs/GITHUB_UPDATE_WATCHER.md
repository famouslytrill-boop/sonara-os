# GitHub Update Watcher

The GitHub Update Watcher is report-only. It tracks selected external repositories for release, license, security, and breaking-change review.

## Watchlist

- `github/spec-kit`
- `usebruno/bruno`
- `cocoindex-io/cocoindex`
- `ruvnet/ruflo`
- `firecrawl/firecrawl`
- `chatwoot/chatwoot`
- `frappe/erpnext`
- `nextcloud/server`

## Rules

- Do not auto-update production dependencies.
- Do not auto-install new repositories.
- Do not auto-merge updates.
- Create reports only.
- Owner approval is required before adoption.
