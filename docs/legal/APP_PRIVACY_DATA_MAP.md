# App Privacy Data Map

- Account data: used for login, owner bootstrap, organization access, and admin gating.
- Email address: used for account, support, and notifications after provider setup.
- Phone number: optional planning field; phone/SMS providers are not live by default.
- Support data: support/contact/feedback form content; storage/email depends on configured providers.
- Uploaded files: private by default and scoped to organization records.
- Photos/videos: optional Creator Studio media, rights review required.
- Audio/voice: optional voice tools, consent and listening indicator required.
- Contacts: never auto-imported; selected import and consent required.
- Location: optional service-area or venue planning only.
- Usage analytics: privacy review required before enabling third-party analytics or session replay.
- Crash/performance data: must redact secrets and private customer data.
- Payment records: provider references only; no raw card/CVV storage.
- Device identifiers if used: require privacy review.
- Push notification tokens: optional future notification setup and consent required.
