# Open-Source License Policy

Status: launch policy draft.

## Baseline

External projects can be referenced during planning, but source code must not be copied or vendored
until license review is complete.

## GPL and AGPL

- GPL projects are high license risk.
- AGPL projects are critical license risk.
- Do not copy GPL/AGPL source into proprietary app packages.
- Self-hosting GPL/AGPL systems requires isolated deployment planning and documented obligations.

## Allowed Without Further Action

- Reading public docs for architecture inspiration.
- Recording a project in the intake registry.
- Linking to the external repository as a candidate.

## Not Allowed Without Review

- Copying source code, UI, templates, prompts, schema, or tests.
- Installing a candidate as a production dependency.
- Vendoring a candidate repository.
- Shipping a hosted copy of a candidate project.
- Using a third-party brand as if it were a SONARA partner.

## Decision Owners

Legal review and owner approval are required before any integration status can move beyond
reference/concept review.
