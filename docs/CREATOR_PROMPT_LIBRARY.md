# Creator Prompt Library

Creator Studio prompt templates help creators draft release plans, captions, content calendars, proof-card copy, and rights-aware planning notes.

Rules:

- Respect rights, licensing, consent, and provenance records.
- Do not claim rights that are not documented.
- AI voice, visual, or video prompts intended for public output require owner approval.
- Do not impersonate public figures, customers, employees, or third parties.
