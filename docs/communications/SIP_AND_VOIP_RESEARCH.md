# SIP and VoIP Research

Linphone iPhone is a restricted SIP/VoIP reference only. It is not integrated and does not create a live calling system.

Blocked:

- Source copying without legal review.
- GPL code bundling in closed-source product code.
- Robocalling.
- Covert recording.
- Emergency dispatch claims.
- Hidden call logging.
- SIP credential exposure.
- Automatic customer calling without approval.
