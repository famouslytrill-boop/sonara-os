# SONARA Batch 1–10 Convergence — 2026-09-15

## Objective

Converge all ten research/intake batches, maintained repository registries, uploaded PDFs/diagrams/graphs, model and engine research, Claude instructions, ChatGPT/Codex strategy, and current product/design authority into one governed application architecture without treating research as production execution.

## Authority order

1. production/runtime truth;
2. current SONARA One v3 / Balanced Precision design and correctness authority;
3. maintained formal open-source registry decisions;
4. Batch 10 operational/source evidence;
5. verified external research from Batches 1–7 and 10;
6. historical reference.

Older SONARA Nexus / Prism Wave-era handoffs remain historical where they conflict with current SONARA One authority.

## Repository convergence

`lib/sonara-batch-convergence-engine.cjs` merges Batches 1–10, the requested repository registry, and the maintained open-source registry. Canonical upstreams are deduplicated while source provenance remains visible. The formal open-source registry merges last so its explicit integration/commercial-use decision can narrow older intake claims.

No repository receives execution authority from convergence.

## Commercial/open-source policy

`lib/sonara-model-engine-control-plane.cjs` separates the full repository inventory into permissive candidates, copyleft review, blocked/unknown, and research/review-only classes. A permissive source license alone never overrides a formal commercial-use, conduct, security, or product-policy block.

Selected runtime-placement records include deterministic SONARA rules, Open Media Worker, ComfyUI, ACE-Step 1.5, Wan 2.2, Qwen-Image, Basic Pitch, whisper.cpp, faster-whisper, Demucs, OpenTimelineIO, React Three Fiber, Blender, OpenJarvis, UI-TARS, and OBS Studio. Explicit placement does not download or enable them.

## Source evidence

`lib/sonara-source-evidence-register.cjs` maps uploaded compliance, payments, generative-AI, SaaS, model-registry, open-source, design, market, cross-industry, Claude-design, screenshot, diagram, and graph material into bounded implementation context. Source evidence cannot execute code, authorize providers, prove certification, or override production truth.

## Learning and memory

`lib/sonara-learning-memory-control-plane.cjs` separates repository-native development memory, legacy vector-memory schema, dormant agent-memory schema artifacts, and a future organization-scoped learning/memory runtime. Memory candidates require organization scope, provenance, purpose, retention, and applicable approval. Sensitive credentials and raw payment authentication material are never learnable memory. Semantic retrieval remains optional and provider/model/vector-dimension/runtime gated.
