- repository/open-source registry integrity stays green;
- Batch 1–10 convergence contains all ten batches and deduplicates canonical repositories;
- formal registry decisions override older intake metadata when stricter;
- model/engine registry remains non-executing;
- commercial candidate classification requires both permissive licensing and an allowed commercial-use state;
- blocked/quarantined conduct decisions remain blocked even with permissive licenses;
- learning/memory policy blocks sensitive credentials/payment authentication material and requires scope/provenance/purpose;
- Claude and ChatGPT/Codex strategy records remain non-authorizing;
- source-evidence records remain non-executing and non-certifying;
- public ecosystem routes expose no private configuration values;
- admin live readiness remains protected;
- pnpm install/audit/typecheck/lint/test/build and all required GitHub release/security/tenant gates pass;
- merge only after required checks are green.
