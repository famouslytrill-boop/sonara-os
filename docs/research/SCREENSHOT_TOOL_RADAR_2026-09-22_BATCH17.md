## What was intentionally not installed

No screenshot repository was cloned into SONARA and no package was silently added to production dependencies. This is intentional:

- several projects are GPL/AGPL or noncommercial;
- many are developer/desktop/mobile/OS tools that do not belong in the Vercel request runtime;
- even permissive repositories need a measured product gap, security review, exact version/source pinning and full release evidence before executable adoption.

"Adding a repository to the system" in this batch means adding it to the governed research/control plane with an explicit next action and boundary. Executable adoption remains a separate reviewed change.
