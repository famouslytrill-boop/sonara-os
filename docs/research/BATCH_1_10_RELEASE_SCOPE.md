# Batch 1–10 Release Scope

This release advances SONARA's intelligence/control-plane architecture. It does not bulk-install third-party repositories or silently enable providers.

## In scope

- ten-batch repository/research convergence and deduplication;
- maintained formal open-source registry integration;
- source-evidence mapping for uploaded PDFs/diagrams/graphs/research;
- model/engine runtime placement and commercial-open-source classification;
- governed learning/memory policy and truthful readiness;
- Claude skill and ChatGPT/Codex strategy convergence;
- public ecosystem metadata and founder/admin control-plane surfaces;
- current v3 / Balanced Precision authority correction in agent/project memory;
- regression tests for authority, repository deduplication, commercial-use decisions, memory safety, and route exposure.

## Not in scope

- downloading or installing every external repository;
- activating unconfigured model/provider workers;
- representing GPL/AGPL/custom-license code as embedded hosted dependencies without review;
- enabling semantic retrieval before provider/model/vector-dimension/runtime verification;
- claiming a ChatGPT app/plugin is installed from repository files alone;
- claiming compliance or certification from configuration evidence;
- changing production account secrets or provider credentials.
