# HyperFrames Review

Repository: `heygen-com/hyperframes`

Status: high-value HTML-to-video rendering candidate, reference only.

License: Apache-2.0 with review before adapter work.

Blocked:

- Blind production install.
- Copied third-party source.
- Unlimited video rendering.
- Copyrighted asset misuse.
- Fake endorsements.
- Non-consensual likeness.
- Implied vendor partnership claims.
- Unbounded CPU/GPU/FFmpeg jobs.

Production integration requires queues, storage, auth, quotas, tests, safety gates, and human approval.
