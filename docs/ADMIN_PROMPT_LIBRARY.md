# Admin Prompt Library

Admin prompt templates help summarize reports, security findings, reliability incidents, owner daily review items, support notes, and billing context.

Rules:

- Do not paste secrets, tokens, database URLs, webhook secrets, payout details, or customer private data into prompts.
- Security and reliability summaries are decision-support drafts, not proof of compliance or guaranteed uptime.
- Owner daily review prompts should surface pending approvals, blockers, and risks without auto-executing actions.
- High-risk admin outputs require Owner Confirmation Lock before external use.
