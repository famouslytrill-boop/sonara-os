# Vercel Live Setup

Vercel is the preferred hosted path when configured. This repository does not claim Vercel is connected until the project, env vars, domain, and deployment are verified.

## Checklist

- Link the Vercel project.
- Configure production branch.
- Add production and preview environment variables.
- Configure `sonaraindustries.com`.
- Verify SSL.
- Verify build command and output directory.
- Verify security headers through generated `_headers` or host-native settings.
- Protect production deploys with owner approval.

## Required Env

Set values in the Vercel dashboard or CLI. Never commit real secrets.
