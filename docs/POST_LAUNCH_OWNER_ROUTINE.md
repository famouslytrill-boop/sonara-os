# Post-Launch Owner Routine

## Daily

- Review Owner Review Queue.
- Review failed payments and Stripe webhook alerts.
- Review support requests.
- Review security warnings.
- Review onboarding incomplete alerts.
- Review reliability incidents.

## Weekly

- Review GitHub Update Watcher report.
- Review open-source intake changes.
- Review AI cost summary.
- Review pricing and setup-service conversion.
- Review docs and policy changes before publishing.

## Always Require Owner Approval

- Refunds.
- Price changes.
- Payout settings.
- Legal/policy text.
- Customer-facing campaigns.
- Security setting changes.
- Data deletion.
- Publishing proof/reviews.
- AI voice, visual, or video outputs.
- Production deploy by an agent.
