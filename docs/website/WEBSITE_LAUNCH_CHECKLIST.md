# Website Launch Checklist

## Public Routes

Verify home, product pages, pricing, trust, contact, support, help, feedback, legal, research, docs, integrations, API/webhooks, status, and changelog routes.

## Metadata

- Browser title uses SONARA Industries or current product names.
- Canonical URL points to production.
- OpenGraph and Twitter metadata use SONARA assets.
- Sitemap and robots use the production domain.
- Favicon and manifest point to current SONARA brand assets.

## Public Claims

Do not claim provider integrations, email, payments, app-store releases, or database migrations are live until tested and approved.
