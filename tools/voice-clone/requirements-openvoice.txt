# decision -- torch alone is a gigabyte or so, and the checkpoints are more --
# and because the app is designed to work, and to refuse honestly, without it.
#
# OpenVoice V2 also needs two things pip cannot install from a version pin,
# so follow its own instructions after this file:
#
#   git clone https://github.com/myshell-ai/OpenVoice && pip install -e OpenVoice
#   pip install git+https://github.com/myshell-ai/MeloTTS.git
#   python -m unidic download
#
# Then download the V2 checkpoints linked from OpenVoice's README and unpack
# them to ./checkpoints_v2 (or set OPENVOICE_CHECKPOINTS).
#

# written on had no GPU and could not download the checkpoints, so this path
# has never been executed.
